## 1. Despliegue de una página personal en Hosting estático con CDNs

El objetivo de esta práctica es crear un sitio web personal en [GitHub Pahes](https://docs.github.com/es/pages) con tu nombre y apellidos, una breve descripción sobre ti, un enlace a tu perfil de GitHub y enlaces a los repositorios de tus prácticas de los distintos módulos del Ciclo. La página deberá ser accesible desde la dirección `https://nombreusuario.github.io.`

Finalmente, crea un repositorio llamado `curriculum` con estilos [Bootstrap](https://getbootstrap.com/) adaptativo a cada dispositivo, donde subirás tu currículo en formato HTML y lo publicarás en GitHub Pages. El currículo será accesible desde `https://nombreusuario.github.io/curriculum`. Deberás aportar imágenes de su renderizado usando la herramientas de desarrollador de tu navegador para varios dispositivos.

**Ventajas**

* Muy eficiente para sitios web estáticos.
* Es gratuitos y muy económicos.
* Mejora la velocidad de carga de los sitios web estáticos.

**Inconvenientes**

* Esta solución está limitada a contenido de sitios web estáticos.

### 1.2. Tareas a realizar

A continuación se describe brevemente las tareas que tendrá que realizar.

1. Desplegar un sitio web personal empleando [GitHub Pages](https://docs.github.com/es/pages/getting-started-with-github-pages/creating-a-github-pages-site) que será accesible desde `https://nombreusuario.github.io.`
2. Añadir un repositorio llamado `curriculum`con el currículo del alumno, que será accesible desde `https://nombreusuario.github.io/curriculum`
3. Añadir en un directorio las pruebas gráficas del renderizado web adaptativo

### 1.3. Entregables

Deberá crear un repositorio en [Github](https://github.com/) con el nombre de la práctica y añadir al profesor como colaborador.

El repositorio debe tener el siguiente contenido:
* Un **documento técnico** con la descripción de todos los pasos que se han llevado a cabo.
* Los **scripts de Bash** que se han utilizado para automatizar la instalación y configuración de Webmin, así como de las herramientas adicionales.

Además del contenido anterior puede ser necesario crear otros archivos de configuración, que deberán ser documentados e incluidos dentro del entregable. A continuación se muestra un ejemplo de cómo puede ser la estructura del repositorio:

```
.
├── README.md
└── images
    ├── imagen1.jpg
    ├── ...
    └── imagen1.jpg
```
